# English Club — учебная программа

## Профиль ученика

| Параметр | Значение |
|----------|----------|
| Возраст | взрослый |
| Старт | A1 (минимальные знания) |
| Длина урока | 30–40 минут |
| Язык интерфейса / пояснений | русский |
| Цель | разговорный английский; понимание художественной литературы; фильмы/сериалы (наслух и «насмотр»); общение в англоязычных странах |

## Долгосрочная траектория

```
A1 Foundations  →  A2 Everyday  →  B1 Confidence  →  B2 Fluency bridge
   24 урока          28 уроков         32 урока            24 модуля
   речь + база       travel + stories  литература light    фильмы / книги
```

К целям «художка + фильмы» ведёт вся цепочка. На A1–A2 — грамматика, ядро словаря, устная база; с конца A2 — graded readers и EN-субтитры; на B1–B2 — аутентичные тексты и видео.

## Принципы курса

1. **Один урок = одна грамтема (или навык) + тематический словарь + speaking/listening output.**
2. **Спираль:** тема возвращается в новых контекстах (travel → story → film scene).
3. **Словарь через контекст:** фразы и коллокации, не голые списки.
4. **Практика ~70% / теория ~30%.**
5. **SRS** для слов, чанков и типичных ошибок грамматики.
6. **Постепенный input:** диалоги → короткие истории → graded readers → film clips → authentic.

### Структура урока (30–40 мин)

| Блок | Время | Содержание |
|------|-------|------------|
| Warm-up / review | 4–5 мин | 5–8 карточек SRS + 2–3 предложения из прошлого урока |
| Explain | 5–7 мин | правило простым языком + 4–6 примеров |
| Controlled practice | 8–10 мин | drills: form, gap, reorder, error fix |
| Vocabulary in context | 6–8 мин | 10–14 слов/фраз в мини-диалоге или тексте |
| Use it (production) | 8–10 мин | speaking prompts / dialogue / short writing |
| Cool-down | 2–3 мин | summary + «что повторить завтра» |

На Level 4 блоки могут смещаться в сторону Book Club / Scene Lab / Debate.

## Сквозные треки

### 1. Vocabulary Core

- ~1200–1500 активных единиц к концу A2; ~2500–3000 к B1  
- Карточки: слово/фраза / пример / аудио  
- SRS: день 0 → 1 → 3 → 7 → 14 → 30  
- Колоды: Travel Survival, Story Words, Film Phrases, Phrasals  

### 2. Listening → Movies

| Этап | Материал | Поддержка |
|------|----------|-----------|
| A1 | slow dialogue | transcript |
| A2 | short clips 30–90 сек | EN subs |
| B1 | scenes 2–5 мин | EN → без на повторе |
| B2 | 10–15 мин episode/film chunk | без RU; EN optional |

### 3. Reading → Literature

| Этап | Материал |
|------|----------|
| A1 | micro-texts 40–120 слов |
| A2 | graded readers A2 |
| B1 | graded B1 + adapted short stories |
| B2 | YA / contemporary light → classics light |

### 4. Speaking → Travel

Airport → hotel → food → transport → shopping → emergency → small talk  
С A2: непредвиденные повороты (lost bag, wrong order, delay)  
С B1–B2: жалобы, переговоры, stacked scenarios

## Метрики прогресса

- Streak и минуты занятий  
- Размер активного словаря (SRS mature cards)  
- Accuracy по грамтемам  
- Listening gist %  
- Завершённые travel scenarios  
- Reading: главы / страницы  
- Watching: минуты без RU-субтитров  

---

## Рекомендуемый ритм

| Режим | Нагрузка |
|-------|----------|
| Комфорт | 3 урока/нед + SRS 8–10 мин/день |
| Активный | 4–5 уроков/нед + 1 input day (reader/clip) |
| Travel boost | колода Travel Survival + scenarios |

Оценка: **A1 → уверенный A2 ≈ 4–6 месяцев**; **до комфортного B1 с книгами/фильмами ≈ 10–14 месяцев**; **B2-bridge habit ≈ +4–6 месяцев**.
